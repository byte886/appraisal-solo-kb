# 新窗口怎么接手这个项目（开新任务窗口 · 固定 SOP）

> 目标：**只要知道仓库位置，新窗口就能接手**，不需要持有人重讲背景。
> 权威恢复顺序以根 `AGENTS.md` §7 为准；本文件规定"开新窗口"这句话触发的固定动作：
> **老窗口收口 → 两步开窗 → 新窗口六问验收**。
> 实测经验（2026-09，来自姊妹仓 astock-quant）：新建窗口时"选项目文件夹"**不保证**项目 AGENTS.md 被自动注入，
> 所以第 2 步那句标准句是兜底，**两步都要做**。

## 0. 触发词（听到就走本 SOP，不自创交接长文）
持有人说任一句，当前窗口（=**老窗口**）立即按 §1 收口：
- "上下文有点大了，开个新任务窗口" / "换新窗口" / "新窗口接手" / "再开个窗口接着干"。

## 1. 老窗口收口（开窗之前，AI 做，四步）
1. **状态落盘**：本轮重要讨论/决策往 `docs/HANDOFF.md` §1 倒序追加一条；更新 `03/TASK_STATUS.md`、`ISSUES.md`（易变进度只留台账）；转发的资料已按 `外脑喂养SOP.md` 归位。
2. **一致性自查**（本仓无体检脚本，人工过一遍）：README/总纲/台账与现状一致；新增文档已在 `docs/README.md` 或根 README 登记；无断链；无个人信息/凭证明文。
3. **提交**：`git add -A && git commit`；需要跨机/给协作者则 `git push`。**仓库转私有前，`*_私有.md`、含联系人台账、inbox/ 已被 gitignore，只留本地，确认没误加**（`git status` 看不到它们即正确）。
4. **发操作指引**：把 §2 两步和标准句**原样**发给持有人，不写长篇交接段（仓库自描述，结论都在仓里）。

## 2. 开窗两步（本机，最简）
1. 新建任务窗口时，**项目文件夹选成 `~/Desktop/appraisal-solo-kb`**（不要用系统默认的 `~/Doubao/chats/...` 临时目录，那里没有本仓规则）。作用：定位仓库、工作目录落在项目里；但不保证规则自动注入，故第 2 步不能省。
2. **只发这一句（标准句，原文照发）**：

   ```
   接手这个项目，按 AGENTS.md §7 冷启动，先把冷启动六问答给我听，再等我派活。
   ```

   读什么、什么顺序、红线、六问，全由仓库根 `AGENTS.md` §7 与 `docs/` 接管。

## 3. 新窗口验收（怎么算接手成功）
- 新窗口应**不翻旧聊天**就答出冷启动六问：
  1. **项目是什么、为谁做、主线与第二曲线**；
  2. **现在在哪个阶段、最近完成了什么**；
  3. **下一步是什么、哪些等她拍板、AI 推荐哪个**；
  4. **开放问题/坑/待核实清单**（ISSUES、8 问、待核实）；
  5. **红线**（合规四条 + 隐私/公开仓 + 在职不撬单）；
  6. **关键资源**（仓库与飞书位置、两个台账、外脑文档、local-trajectory-recall 怎么找回旧窗口原话）。
- 老窗口可让新窗口把六问答出来，抽查 1~2 条与 `TASK_STATUS.md` 对得上。
- 答不上、或文档自相矛盾 → **不开工**，先修文档（说明仓库自描述有缺口）。

## 4. 兜底（换电脑 / 无法选项目文件夹 / 网页版）
- **新 Mac 先 clone**：`git clone git@github.com:byte886/appraisal-solo-kb.git`，文件夹选克隆目录，其余同 §2。
  注意：仓库转私有前 clone 得到的是**公开版**，`创业者画像_私有.md`、含联系人台账不在远程，需另行安全传递。
- 没法让系统读到项目 AGENTS.md 时，把下面整段发给新窗口（已带路径与阅读顺序）：

```
接手一个进行中的项目，仓库在 ~/Desktop/appraisal-solo-kb（GitHub: github.com/byte886/appraisal-solo-kb，当前 public，main）。
这是海口一名三证齐全的评估公司技术总监"合规独立单干、补获客短板"的知识库与外脑项目，处于调研筹备期（本人未离职）。

请严格按仓库根 AGENTS.md §7「新会话恢复顺序」冷启动，不要凭文件名猜测，按顺序读：
1. AGENTS.md → 2. README.md → 3. PROFILE.md → 4. 00_项目总纲.md
→ 5. docs/README.md（外脑文档地图）→ 6. docs/HANDOFF.md（§1 倒序日志 + §3 当前纠结 + §4 想法停车场）
→ 7. 03_进行中的任务/TASK_STATUS.md → 8. 03_进行中的任务/ISSUES.md
→ 9. docs/创业者画像.md（本机另有 docs/创业者画像_私有.md 含资金/家庭等敏感字段，仅本地可读）。
读完把六个答案讲给我听：项目是什么/主线与第二曲线、现在哪个阶段最近完成什么、
下一步与待我拍板项及你的推荐、开放问题与待核实、红线、关键资源位置。六问答不上来先修文档再动手。

红线：只讲人证合一合法路径，不输出挂证人证分离/围标/回扣；在职不撬现单位客户、不变更证书；
机构资质/名单/电话/政策用前必须官方复核，查不到标【待核实】不编造；
真实联系人/个人信息不入公有仓（*_私有.md、含联系人台账只留本地）。
现在请先完成冷启动并汇报六问，再等我布置具体任务。
```

## 为什么至少要"给仓库位置"这一步
新对话默认不知道要接手**哪个**项目（电脑上不止一个仓）。位置一旦给了，**读什么、什么顺序、答哪六问、红线是什么，全部由仓库里的 AGENTS.md 和 docs/ 接管**；标准句再强制一次冷启动，不依赖自动注入是否生效，也不需要持有人解释来龙去脉。
