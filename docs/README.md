# docs · 创业者外脑文档地图

> 本目录是"创业者外脑"的治理层（方法论与交接），不是结论成品（成品在 `01_`）也不是原始素材（在 `09_`）。
> 范式借鉴桌面 `astock-quant` 的"外脑 + HANDOFF + 新窗口接手"机制，按本项目（评估师独立创业、纯文档型）裁剪。

## 先读什么
| 你要做什么 | 读哪篇 |
|---|---|
| 理解"外脑是什么、怎么运转" | [创业者外脑.md](创业者外脑.md) |
| 快速了解创业者本人与各方角色 | [创业者画像.md](创业者画像.md)（公开版；完整敏感画像在本地 `创业者画像_私有.md`，不入库） |
| 新任务窗口接手这个项目 | [新窗口接手开场白.md](新窗口接手开场白.md) |
| 看一路怎么决策、现在卡在哪 | [HANDOFF.md](HANDOFF.md)（活日志，倒序） |
| 喂素材/转发资料/把其它窗口的思考收进来 | [外脑喂养SOP.md](外脑喂养SOP.md) |

## 与六槽位的关系（不另起炉灶）
- `00_项目总纲`：目标/阶段/成功标准（项目视角）。
- `01_结论与产出`：可对外/可执行的成品。
- `02_决策记录`：ADR（只增不改）。
- `03_进行中的任务`：TASK_STATUS/ISSUES/两个台账（活态）。
- `09_调研底稿与素材`：源报告、`同业来件/`（别人发的资料）、`跨窗口思考/`（自己其它窗口的产出）。
- `docs/`（本目录）：**让外脑跨窗口不断线**的运转规则、画像、交接日志。

## 维护分工（单一真相源）
- 易变进度 → 只写 `03/TASK_STATUS.md`，别处放指针。
- "怎么想过来的、为什么"→ `docs/HANDOFF.md` 倒序日志；定型的重大取舍 → `02/ADR`。
- 稳定的人物/角色事实 → `docs/创业者画像.md`（敏感字段进本地私有版）。
- 原始素材 → `09/`，只读；结论上移到 `01/02`。
