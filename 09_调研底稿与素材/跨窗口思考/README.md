# 跨窗口思考（自己在其它豆包窗口的产出）

> 与 `../同业来件/`（**别人**发来的资料）相对，本目录收**持有人自己**在其它任务窗口/普通对话里产生的、与独立创业相关的调研、问答、方案、灵感。
> 机制总说明见 `../../docs/外脑喂养SOP.md` §三。

## 目录约定
- `inbox/`：跨窗口导出的**原始**内容（local-trajectory-recall 导出件、分享链接抓取件）。
  **已 gitignore、不入任何远程**：原文可能含系统提示、token、个人隐私，只在本机供审阅。
- `NNN_主题_日期.md`：审阅去重、**脱敏并剔除系统信息后**的归档件（编号顺延，只留观点正文）。

## 采集方式
1. agent 工作任务窗口：`python3 ~/Doubao/skills/local-trajectory-recall/scripts/recall.py search 关键词 --all`，命中后 `export` 到 `inbox/`。
2. 云端普通对话：用该对话的分享链接（`doubao.com/thread/<id>`）在新窗口读取后整理。
3. 触发：新窗口冷启动后、持有人说"收一下我在另一个窗口聊的 XX"、每周自查时。

## 审阅三问（每份 inbox 材料）
- 与独立创业相关吗？（无关丢弃）
- 是稳定结论、一次性问答，还是待验证想法？（结论上移 01/02/画像；想法进 `docs/HANDOFF.md` §4 停车场）
- 含个人/联系人/敏感信息吗？（脱敏后才允许离开 inbox）
