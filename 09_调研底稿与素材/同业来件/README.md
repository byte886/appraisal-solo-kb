# 同业来件 · 收件箱与判断规则

> 用途：评估师同行/合作方/客户陆续发来的**外部资料**（宣传册、方案、报价、名单、课件、公告截图等）统一先进这里，
> 做"值不值得留、归到哪、能不能外传"的判断；是**一手外部素材**，只读、不改原件。

## 收件三步（每份来件都做）
1. **原件入此目录**：保留原文件名（可加日期/来源前缀），不改动、不删页。
2. **写一条索引**（下表）：日期、来件人角色（不写私人电话/微信）、资料类型、核心价值、敏感级、去向。
3. **有复用价值的另写一张"情报卡/提炼卡"**（同目录，`YYYY-MM_主题_情报卡.md`）：把可复用的事实、方法、待核实点、对我方动作写清楚；**原件是别人的版权，提炼用自己的话，不整段照抄**。

## 去向路由（判断后）
- 只是一次性参考、无复用价值 → 不留或仅留原件，不写卡。
- 可复用的**服务线/方法论/营销范本/行业情报** → 留本目录 + 情报卡。
- 变成正在跟进的**具体客户/机构线索**（有名称、要接触）→ 升级到 `03_进行中的任务/客户开发台账/`（需求侧）或 `合作线索台账/`（供给侧），本目录留指针。
- 可公开的通用方法论，脱敏后可进入 `01_结论与产出/`；含具名机构/个人/报价的不进公开成品。

## 敏感级与版权（重要）
- 标注：【公开传播】对方本就公开发布 / 【内部资料】对方私下发、限内部参考 / 【保密】标注保密或涉客户数据。
- 【内部资料】【保密】**不得对外转发、不得放进公开成品/公开仓库正文**；本仓库当前为公有仓，这类资料只作个人学习，**建议仓库转私有后再沉淀更多同业来件**（见根 README 与安全基线）。
- 来件中的数据、案例、政策口径多为"一方宣传"，引用前按情报卡里的"待核实"清单回到官方/公告核对，不直接当结论。
- 不登记来件人的私人手机/微信/邮箱到仓库；需要跟进联系时放本地私有台账（不入库）。
