# 创业者外脑 · 这个项目的"第二大脑"怎么运转

> 一句话：**让任何一个新的 AI 任务窗口，只要拿到本仓库路径，就立刻是一个"懂你情况、记得所有决策和线索、会推着你走"的创业参谋（chief-of-staff），而不用你每次重讲背景。**
> 范式来自桌面 `astock-quant` 的"交易外脑"（克隆操盘手判断、跨窗口不断线）；不同的是，**这里要克隆和服务的"创业者"就是持有人本人**。

## 一、外脑替你记住什么（四类长期记忆）
1. **你是谁**：三证、技术强/获客弱、在职、资金与时间约束、家庭与风险偏好 → `创业者画像.md`（敏感字段在本地私有版）。
2. **决定过什么**：路径取舍（轻资产、人证合一、第一年四渠道）、为什么这么选 → `02_决策记录/` + `HANDOFF.md`。
3. **正在发生什么**：两个台账（供给侧合作机构、需求侧园区/客户）、待办、待核实、待你拍板的 8 问 → `03_进行中的任务/`。
4. **进来的素材与想法**：同业来件、其它窗口的调研/灵感、实地接触反馈 → `09/` 两个收件箱 + HANDOFF 想法停车场。

## 二、外脑的三个固定动作
- **接手即懂**：新窗口按 `新窗口接手开场白.md` 冷启动，答得出"六问"再开工（项目/阶段/下一步与推荐/坑/红线/资源）。
- **来件即判**：你转发任何资料（评估师同行发的、自己在别的窗口聊的），按 `外脑喂养SOP.md` 当场判断：留不留、归哪个槽位、要不要升级成线索/决策。
- **周期性推一把**：每周一次 15 分钟自查（见下），把想法收拢、把待核实销项、提醒"当前阶段最重要的一件事"，并防止第二曲线想法挤占第一年主线。

## 三、每周 15 分钟自查节奏（建议固定到周五）
1. 清两个收件箱（`09/同业来件`、`09/跨窗口思考/inbox`）：归档、提炼、删无价值。
2. 更新 `03/TASK_STATUS.md`：本周做了什么、下周第一件事、卡住等谁。
3. 有重要讨论/决策 → `HANDOFF.md` §1 倒序追加一条（聊了什么→结论→为什么）。
4. 想法停车场过一遍：新想法是"第一年主线"还是"第二曲线"？第二曲线默认挂起、附恢复条件，不当下铺摊子。
5. 待核实清单（12345/主管部门/工商备案）能电话核的当场安排。
6. 提交 git（仓库转私有前，敏感件只留本地）。

## 四、外脑的边界（它不做什么）
- **不替你拍板真金白银/职业走向的决定**：形态选择、离职时点、资金投入、是否合作，给推荐+理由+代价，决定权在你。
- **不替你做违规动作**：挂证人证分离、围标、回扣、撬现单位客户，一律不输出（见 AGENTS §4 合规红线）。
- **不编造**：机构资质、政策、名单、电话查不到就标【待核实】，不拿"应该是"填充。
- **不被想法带走**：你想法多（互联网、上下游、行业工具、挂靠、各种细分服务线），外脑负责收口排序，而不是来一个做一个。

## 五、和其它仓库/工具的分工
| 事项 | 去哪 |
|---|---|
| 评估创业全部知识与本外脑 | 本仓 `appraisal-solo-kb` |
| 项目管理方法论（阶段门/台账/ADR） | 自定义技能 `project-manager` |
| 安全/凭证/公开仓检查 | 自定义技能 `security-baseline` |
| 找回"以前在别的窗口聊过的原话" | 技能 `local-trajectory-recall`（跨会话检索本机 trajectory，原文不入 git） |
| 视频/公众号等多平台素材采集转写 | 桌面仓 `multiplatform-content-pipeline` |
| 在线协作/给协作者看 | 飞书知识空间「海口评估独立创业调研」（连接器开启时同步） |
