# 外脑喂养 SOP · 素材、想法、跨窗口思考怎么收进来

> 管"外脑吃什么、怎么消化"。外脑的价值取决于持续喂料；本 SOP 让每一份来件都有确定归宿，不漏、不堆、不污染。
> 配套：运转宪章见 `创业者外脑.md`，交接见 `新窗口接手开场白.md`，想法停车场见 `HANDOFF.md` §4。

## 一、五类输入与唯一归宿（一条信息只落一处）
| 输入类型 | 长什么样 | 第一落点 | 消化后去哪 |
|---|---|---|---|
| **① 同业/他人来件** | 评估师同行、机构、群里发来的手册/名单/报价/课件（微信文件、链接、截图） | `09/同业来件/`（先复制出微信容器，原件只读） | 有复用价值→出情报卡/更新台账并在该目录 README 登记；无价值→不留 |
| **② 自己其它窗口的产出** | 你在别的豆包任务窗口做的调研、问答、方案、灵感 | `09/跨窗口思考/inbox/`（本地，gitignore） | 提炼后编号归档到 `09/跨窗口思考/`，结论上移 01/02，想法进停车场 |
| **③ 实地接触反馈** | 打电话、跑园区、见渠道后的结果、对方口径、报价 | `03/TASK_STATUS.md` 销项；**联系人/电话只进本地私有台账** | 公开规律写进台账/README；个人信息不入库 |
| **④ 决策与取舍** | 你拍板的方向、否决的方案 | `02/决策记录/ADR-NNN`；过程写 `HANDOFF.md` §1 | —— |
| **⑤ 零散新想法** | "能不能也做个工具/做短视频/搞上下游" | 先记 `HANDOFF.md` §4 想法停车场 | 判主线/第二曲线；到恢复条件再升级为工单 |

## 二、来件处理三步（AI 收到任何转发资料时执行）
1. **只读解析**：微信容器内原件只读，先复制到会话/项目目录再打开；不改动原件。
2. **判价值与去向**（回答三问）：
   - 这是**需求侧**（客户/园区/政策）、**供给侧**（合作机构/挂靠/分公司）、**服务线情报**（细分业务怎么做、怎么收费、获客漏斗），还是**仅参考/无价值**？
   - 含不含第三方版权、个人姓名电话、未公开信息？（定敏感级：公开传播 / 内部资料 / 保密）
   - 要不要升级成台账线索、待核实项或行动工单？
3. **归位 + 登记 + 提炼**：原件进对应收件箱；在该收件箱 README 索引登记一行；高价值的出一张情报卡（事实 / 待核实 / 对我方动作 / 版权提醒）；更新 TASK_STATUS/CHANGELOG；提交（敏感件按 §四处理）。
> 已固化的长期规则：**以后评估师同行发来资料，默认由 AI 按上述判断归档，不必每次问**；拿不准敏感级先按"内部资料"从严处理。

## 三、跨窗口思考怎么收（对接其它任务窗口）
持有人可能在多个豆包窗口里零散聊创业相关内容，两条采集通道：
- **本机工作任务（agent）窗口**：用技能 `local-trajectory-recall` 跨会话检索/导出原话：
  - `python3 ~/Doubao/skills/local-trajectory-recall/scripts/recall.py list`（找有哪些窗口）
  - `… search 关键词 --all`（跨全部主会话搜，如"评估 获客 挂靠 园区 知识产权"）
  - `… export out.md --id <会话id片段>`（导出某窗口）
  - 导出原文先放 `09/跨窗口思考/inbox/`（gitignore，**原文不入 git**，里面可能有系统提示/token/隐私）。
- **普通对话/云端内容**：豆包普通对话正文可能不落到本机，走该对话的"分享链接"（`doubao.com/thread/<id>`）在新窗口打开读取。
- **审阅→归档→提炼**：剔除与创业无关的误召回；有价值的去重后编号存 `09/跨窗口思考/NNN_主题_日期.md`（只留观点正文，不带系统提示/密钥/个人隐私）；稳定结论上移到画像/HANDOFF/01。
- **触发时机（靠记忆，不挂定时）**：①新窗口冷启动后顺带扫一次；②持有人说"我在另一个窗口聊过 XX，你收一下"；③每周自查时。

## 四、隐私与公开仓纪律（仓库转私有前从严）
- 入公有仓的只能是**可公开的通用结论**；真实姓名/电话/微信、客户与联系人、本人家庭/资金/在职出走细节，一律不入库。
- 三类归宿（同 security-baseline）：能脱敏成通用内容→脱敏后明文随仓；不能脱敏但有价值→放本地 `*_私有.md`/私有台账（gitignore）或加密 `.enc`；无价值→删。没有"先塞仓里以后再说"。
- 第三方手册/课件默认"内部资料"，**不公开发布、不全文外传**，只提炼观点；来源与版权在情报卡注明。
- 提交前 `git status` 确认 `inbox/`、`*_私有*`、`*联系人*` 没被暂存。

## 五、每周自查（与 `创业者外脑.md` §三同节奏）
周五 15 分钟：清两个收件箱 → 更新台账与 TASK_STATUS → HANDOFF 倒序补日志 → 过想法停车场 → 排下周第一件事 → 提交。
每月末额外：把当月已验证的判断固化进 01 成品/画像；把"做不通/不做了"的方向记 Won't 及原因，避免以后重复试。
