# ADR-001 · 立项与"轻资产、合规先行、获客正规路径"的起步方向

- 状态：Accepted
- 日期：2026-09-09（2026-09-22 随仓库建立补录）
- 决策者：持有人（AI 提供调研与方案对比，不替持有人拍板）

## 背景
持有人三证齐全、技术强但获客弱，希望独立单干；启动资金有限（曾估 3 万，实际有弹性），
并听说"很多人靠私人关系跑政府"。需要在多种起步形态与获客方式中确定方向。

## 决策
1. **先有合规机构、再谈执业**：不走"个人接活/挂靠出借资质"，采用工商登记 + 领照 30 日内"一照三备"，
   或人证合一的事业合伙人 / 真实入股 / 分公司合作形态。
2. **轻资产起步**：优先合伙制微型所或机构内事业合伙人，控制固定成本与空窗风险，不一开始重资产铺摊子。
3. **获客走正规路径**：以"入库 + 投标 + 轮候/摇号 + 口碑转介绍"替代利益输送；政府/法院/银行入库多为零费用。
4. **第一年聚焦四个最快现金流渠道**：财税代账转介绍、会计师所合作、熟人私域、中介超市入驻；
   政府/银行/法院库按窗口期提前播种。
5. **第二曲线不喧宾夺主**：互联网作为信任放大器（私域 + 本地专业账号），上下游协同（征拆专家辅助人、
   协会授课、不动产登记代理、不良尽调分润）优先于自建工具；起步阶段不做 SaaS。

## 放弃的备选
- 直接挂靠、只挂证不实际执业：触碰人证分离红线，可致罚款、吊销、终身禁业，放弃。
- 靠请客送礼/利益输送换政府业务：违法且不可持续；且海口银行派单已系统随机化，关系不能决定具体派单。
- 一上来重资产设大所、广招业务员：与有限资金和获客短板不匹配，风险高，后置。
- 以互联网/工具产品为主业：评估需求低频、本地化、信任驱动，且已有成熟玩家，作为第二曲线而非主业。

## 后果与待验证
- 降低了启动资金与合规风险，但前期收入依赖合作渠道与口碑，需要主动维护人脉与响应速度。
- 关键假设（海南备案人员口径、劳动合同/持股约束、各库窗口期、分公司合作条款）列入附录 C 与 ISSUES 逐项核实。
