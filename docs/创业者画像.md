# 创业者画像与角色定位

> 给新窗口/未来协作者看：这个项目为谁做、谁拍板、谁是资源方、该怎么和她打交道。
> **公开版**只保留可公开的职业画像；含年龄/家庭/资金/在职出走等敏感字段的完整版在本地
> `docs/创业者画像_私有.md`（已 gitignore，仓库转私有后再并入；新窗口在本机可读）。
> 易变的"现在做到哪"不写这里，以 `03/TASK_STATUS.md`、`HANDOFF.md` 为准。

## 1. 角色一览
| 参与者 | 角色 | 一句话 |
|---|---|---|
| **持有人（创业者本人）** | 发起人 / 唯一决策者 / 技术核心 | 三证齐全的评估公司技术总监，技术与质控强、获客弱，谋划合规独立 |
| **AI（外脑）** | 参谋 + 项目经理 + 研究员 | 调研、归档、判断来件、收口想法、推进度、做核验清单；不替她拍板 |
| **合作评估机构（供给侧）** | 挂靠/分公司/事业合伙人候选 | 见 `03/进行中的任务/合作线索台账/` |
| **园区/企业（需求侧）** | 终端客户与渠道闸门 | 见 `03/进行中的任务/客户开发台账/`（园区平台、企业秘书、入驻/风险企业） |
| **同业评估师** | 资料/经验来源，潜在竞合方 | 经微信等发来手册/名单/打法，先进 `09/同业来件/` 判断 |
| **渠道节点（人）** | 转介绍/协作网络 | 财税代账、会计师所、律所、银行客户经理、测绘尽调同行、园区企业秘书 |
| **潜在市场合伙人** | 补获客短板的合伙人 | 尚未找到，属第一年之后的关键缺口 |

## 2. 创业者职业画像（公开版）
- **资质**：房地产估价师、土地估价师、资产评估师"三证"齐全；现任小型评估机构技术总监。
- **地点**：海南海口，主战场海口、可辐射澄迈老城/儋州洋浦。
- **能力结构**：报告与质控/技术是强项；**获客（找客户）是自述短板**，本项目核心就是补这块。
- **方向排序**：传统线下获客为**第一年主线**（财税代账、会计师所、熟人私域、中介超市四渠道先跑现金流）；
  互联网获客、上下游协同、行业工具为**第二曲线**，默认挂起、到点再启。
- **合规姿态**：只走人证合一合法路径（自设微型所 / 事业合伙人 / 合规分公司合作），不碰挂证人证分离。
- **完整敏感字段**（资金空窗、家庭与时间、现单位持股/竞业、三证注册状态、第一年收入目标、8 问答案）在本地私有版。

## 3. 协作风格（从协作过程提炼，待本人确认后固化）
- 高度重视**沉淀与复用**：反复要求建仓、归档、按项目管理范式组织、可跨窗口接手。
- 会持续**转发素材让 AI 判断价值**（"这个也是，你判断"），期望 AI 主动归类而非每次都问。
- 给方向后倾向**授权执行**；但涉及钱、职业走向、合作方选择需要她拍板。
- 想法较多（互联网/上下游/工具/细分服务线），需要外脑**收口排序、防发散**。
- 沟通要结论先行、能落地，不要正确的废话；不确定就说"不确定"。

## 4. 打交道注意点（给 AI）
1. 先给一句话结论和推荐，再展开；她要的是"下一步具体做什么"。
2. 她技术强，不用科普评估专业；要补的是获客/商务/产品化的视角。
3. 在职阶段一切动作以"不碰现单位、不违规"为前提。
4. 动态信息（机构资质、名单、电话、招标）一律提示"使用前复核"，不把宣传口径当事实。
5. 新想法先过主线/第二曲线分流，第二曲线进想法停车场，不挤占第一年动作。
