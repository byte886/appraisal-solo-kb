# 〇、核心结论（一页速览）

1. **全国三业合计约650亿元/年、机构约1.6万家次（含分支与交叉备案）、执业人员约15万人**，但房地产估价2024年起机构与收入双降（全国机构-1.0%、一级机构平均营收-8.0%），土地估价2025年全行业总收费仅23.45亿元、大量机构空转；资产评估仍微增。传统抵押、征收业务收缩，司法/破产、国资、涉税、数据与知识产权资产、咨询顾问成为转型方向。【事实】
2. **海口是全国少有的"政策驱动型增量市场"**：2025年海口新房销售面积455.24万㎡居全省第一；2026年新一轮城市更新9大项目总投资约375亿元、四大区20多个片区滚动征收；江东新区、海口高新区、复兴城、综保区持续供地；海南农商银行2025年10月刚完成不良资产评估机构入围采购——**征收评估、司法/不良、国资、园区土地四条线在海口同时有活**。【事实】
3. **海口机构格局是"小而密、三证合一、总部扎堆国贸/国兴"**：全省资产评估机构85家、执业资产评估师387人；全省房地产估价机构约76家（一级仅6家），绝大多数注册在海口；外来头部以"海南分公司"下沉（沃克森、中威正信、北京亚超、国众联、世联、国房、厦门均达、深圳云上、万隆等），**但分公司多为轻配置，本地关系型、跑腿型、现场型业务仍由本地中小机构承接**。【事实】
4. **"一人公司"法律上不存在，但"1名老板估价师+1名合伙估价师"的微型合伙所是海口真实存在的主流起步形态**：法律最低门槛是合伙制2名评估师（房估另需3名专职注册房估师备三级）。轻资产模式（共享办公/居家+外协）约2–6万元可启动、月固定成本可压到0.8–1.5万元；常规小所（60–100㎡写字楼+2–3名助理）启动约15–30万元、月固定成本3–6万元。【事实+推测，成本为海口2026年市场价测算，见第六章】
5. **对画像的适配判断**：三证齐全在海口是稀缺组合（全省执业资产评估师仅387人，同时持三证者更少）；46岁、技术总监资历正好契合海口"重资历、重口碑、重熟人网络"的市场特性；**建议"在职过渡→合伙微型所/借壳备案→入库跑业绩→再决定是否扩编"的三步走，而不是一开始就租写字楼招全职团队**。【推测，依据见第六章】

# 四、行业趋势（2025–2026）

1. **备案制进入"再监管周期"**：设立门槛仍低（行政备案），但证券备案2025年趋严、土地估价2024年监管规范出台、海南三协会2026.2反不正当竞争意见落地、双随机抽查与报告三级审核趋严——**"进门容易、守规难、入库更难"**。
2. **数字化替代标准化业务**：海南农商行线上评估已按0.6–0.9元/笔采购；个人住宅抵押"秒估"是长期威胁；人的价值转向复杂物业、争议复核、咨询决策。中小机构不自建系统，用成熟SaaS+公共数据即可。
3. **行业橄榄型重构**：三级房估机构2024年全国-6.7%、空转土估机构出清；但一级机构+3.9%、县域与细分赛道仍有活得好的小机构（山东评协让头部主动退出小额业务、为中小机构让空间【一方说法】）。**结论：死的是"壳机构"和"只会做低价抵押单的机构"，不是所有小机构。**
4. **质量竞争回潮**：选聘办法质量权重≥40%、明码标价试点（重庆2025Q3平均收费止跌）、海南三协会联合反内卷——**对技术出身、报告质量过硬的创业者是利好**。

### 模式选择建议【推测】

- **强烈建议先A后B**：先用合伙制微型所跑通6–12个月（入库、摇号记录、征收分户、司法散单、顾问小单），验证自己获客能力，月营收稳定站上5–8万元再升级公司制与场地；
- **"3万元也能起步"成立但很勉强**：2–6万的轻资产区间内，3万元只够开业+约2–3个月零收入空窗，**必须满足三个前提：①合伙人不领固定工资；②不租独立办公室（用工位/住宅，注意部分政府库实地核验经营场所）；③在职期间已储备好首批3–5个确定客户/分包渠道**。预算有弹性的话，备足6个月固定成本+生活费（轻资产口径约12–18万元）会从容得多。
- 海口不存在"必须临街旺铺"的逻辑，评估是B端/G端信任生意，**装修和地段对获客几乎无加分，把钱花在人员资质和案例上**。

## 6.3 海口小评估公司的真实生存状态（现单位参照系）

- **人员规模**：海口中坚机构参保人数多在10–25人（联合振华23人已是一级所体量；大量小所3–8人）。
- **薪酬行情**（2026.9在招）：估价师主流8–15K（职友集：83.4%岗位8–15K，年薪10–18万）；技术总监/负责人级别可达13–20K（海南国扬在招房地产估价师13–18K）；评估助理2–5K；【一方说法】职友集统计海南资产评估师薪资2025年同比-17%、海口地产评估岗样本显示下行——**打工端薪资在缩水，反过来降低了创业的机会成本**。猎聘 https://m.liepin.com/city-hainan/career/fdcgpinggu/
- **业务状态**：腰部小所普遍"银行抵押单养人、征收/司法单赚钱、政府国企单做品牌"；没入库的小所靠大所分包、熟人介绍和散单，价格战明显（交行库折扣已卷到75折）。
- **人才流动**：海口评估圈很小（三业加起来活跃从业者仅千人量级），技术总监级出来独立的路径通常有三条：①带客户合伙新开（最常见）；②整体受让/入股一家已有备案和库资格的小所（买壳，省去1年暂定期，【待核实：海口壳市场价格，行业传闻数万元至数十万元不等】）；③先做自由签字师/技术顾问再过渡。
- **在职状态的正确用法**：不建议裸辞。在职期间完成：合伙人锁定、个人执业会员关系转出预案、首批客户口头意向、各库申报时间表摸排、备用金储备；**同时严守竞业与商业秘密边界，不带走原单位报告底稿与客户资料**。

## 6.4 "三证齐全+技术总监+46岁女性"在海口的个人品牌价值

- **稀缺性**：全省执业资产评估师仅387人；全国房地产估价师平均年龄47岁、行业老龄化、年轻补给不足（2024年房估考试合格率仅13.5%）；**同时持三证且能独立把控三类报告质量的人，在海口属于"一个人就是一个技术中台"的稀缺资源**。【事实+推测】
- **海口市场的信任结构**：G端（征收中心、自规局、法院、税务）和国企选聘极度看重**资历、既往无不良记录、熟人背书、随叫随到**；技术总监头衔+20年左右从业资历（46岁推算）正好命中评标"项目负责人资历"打分项；海南三协会反不正当竞争意见与全国选聘办法（质量≥40%）进一步放大资历与质量的权重。【事实+推测】
- **性别因素（客观分析，不做刻板假设）**：评估是专业服务而非体力/应酬型行业，海口G端客户对女性技术负责人并无系统性不利；细致、稳健、沟通耐心在征收分户（面对被征收户）、税务争议、司法质证场景反而是加分项；需要主动管理的是外勤看楼/下县的体力安排与安全，可通过助理配合解决。【推测】
- **可立刻启动的个人品牌动作**：①加入三个协会的专家库/继续教育讲师候选（省土估协专家库2024年刚扩容，琼土估协发〔2024〕3号）；②整理本人主导过的标杆项目清单（脱敏）作为投标业绩；③在海口征收/司法/国资圈层建立"三证技术专家"标签；④与1–2家一级所建立"他们不愿接的小单/远单分包给你"的互补关系。
