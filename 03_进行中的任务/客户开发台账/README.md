## 这份清单对应哪些评估业务
| 清单对象 | 评估需求场景 |
|---|---|
| 园区管委会/平台公司 | 土地出让底价、征收分户与回迁房定价、园区物业与租金、合资合作/作价入股、采购走中介超市比选 |
| 入驻优秀企业（直客） | 融资抵押（房地产/设备）、股权转让/增资/资产重组、固定资产入账、涉税评估、购地建厂、设备（零关税）入账 |
| 经营欠佳企业（特殊机会） | 破产清算/强制清算、司法评估、不良资产处置、以物抵债、债务重组——对应主报告"司法/破产/不良"主线 |
| 企业秘书/企业服务部 | **批量转介绍节点**（高新区约 130 名企业秘书对接 417 家重点企业），不是终端客户但是渠道闸门 |

## 优先级（海口主战场）
1. **海口国家高新区（一区七园，药谷/美安为主）**：生物医药聚集，上市/拟上市/ST 企业并存——抵押、设备、重组、财报目的评估都多，且企业秘书体系成熟，**首站**。
2. **海口江东新区**：总部经济+临空+持续供地征收，土地/回迁/总部物业评估确定性高（占全省重点园区营收 16.8%）。
3. **海口综合保税区**：半导体检测、保税维修、零关税设备，设备与不动产评估为主。
4. **海口复兴城**：数字经济/跨境，轻资产为主，股权/无形资产评估多（非三证传统强项，可与资产评估/财税伙伴联合）。
5. **海口可辐射**：澄迈老城·海南生态软件园（行政澄迈、紧邻海口，约 1.6 万家企业、股转频繁）；儋州洋浦（占全省园区营收 47%，工业不动产/设备需求大、本地机构少，海口机构可覆盖）。

## 怎么用（合规打法，详见主报告）
- **不直接陌拜企业**。先走园区企业服务局/企业秘书渠道：申请免费政策讲座（示例题《封关后园区企业：出资、股转、增资、设备入账，哪些环节必须做评估？》）→ 企业秘书内训 → 争取进"企业服务机构推荐名录/服务超市" → 讲座后建群持续答疑。对应主报告 **3.4.7 园区招商**。
- 优秀企业名单用于：按园区/产业筛目标、讲座后建群、经财税代账/会计师所/律所渠道交叉引荐（对应 **3.3 企业直客类**、第一年四渠道）。
- 风险企业**不蹭危困、不煽动诉讼/压价**；只通过破产管理人、法院名册、AMC、拍卖行等正规通道承接（对应主报告司法/破产/不良渠道与 P3 法院名册申请）。
- 园区平台公司自身采购走中介超市/比选正式应标，走正规入库流程，不搞利益输送。

## 核验与升级
- 数据为 2026-09 公开口径，**企业经营状态（尤其 ST/立案/退市）变化快**，正式接触前用工商/巨潮/公告复核；园区企业数、营收以园区管理局最新发布为准。
- 升级为 CRM（建议飞书多维表格或本地加密表）：增加 接触状态/联系人/需求类型/来源渠道/下次动作/负责人。
- **隐私**：含真实联系人姓名/电话/微信的跟进版属私有台账，脱敏前不入公有仓（文件名含"私有/联系人/private"，已 gitignore）。
