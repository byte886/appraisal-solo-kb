## 三条最重要的结论（详见主报告第一章）

1. **个人不能接活，"单干"= 先有合规机构再执业**：工商登记 → 领照 30 日内"一照三备"（房估/省住建厅、资产/省财政厅、土估/省自规厅）；挂证不挂章、人证分离是终身红线。
2. **海口是政策驱动增量市场**：城市更新征收、司法破产、金融不良、自然资源框架四条主线并行；政府/法院/银行入库多为**零费用**，正规路径是入库 + 投标 + 轮候，不是利益输送。
3. **推荐轻资产起步**：在职合规铺垫约 3 个月 → 合伙制微型所或机构内"事业合伙人"（人证合一）→ 第一年只押财税代账、会计师所、熟人私域、中介超市四个最快现金流渠道。

## 项目维护规则

- 结论性产出放 `01_`，原始底稿放 `09_`，不混放；关键取舍写 `02_` ADR；正在做的写 `03_`。
- 所有数字/政策标注证据分级与来源；查不到写【待核实】，不编造。动态信息（分支机构、入库名单、电话地址）正式使用前复核。
- 每次显著变更更新 [CHANGELOG.md](CHANGELOG.md)；AI 操作规则见 [AGENTS.md](AGENTS.md)。
